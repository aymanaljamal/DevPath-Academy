API Integration in React

9.1 Introduction to API Integration

Simple Explanation

API integration is how your React application communicates with backend servers. It involves sending and receiving data over HTTP using methods like GET, POST, PUT, and DELETE. This is how your app fetches data, saves user input, and interacts with external services.

Think of API integration like ordering food at a restaurant - you send a request (order) to the kitchen (server), they prepare it, and send back the food (response). The menu items are the available endpoints, and the order is the request.

Technical Explanation

API integration in React typically involves making HTTP requests to backend services to fetch or manipulate data. Common approaches include: - Fetch API: Native browser API - Axios: Popular HTTP client library - React Query: Advanced data fetching library - SWR: Data fetching with stale-while-revalidate

Key concepts: - Endpoints: URL paths for resources - HTTP Methods: GET, POST, PUT, DELETE, PATCH - Headers: Metadata sent with requests - Body: Data sent with requests - Status Codes: Response status (200, 404, 500, etc.) - Authentication: API keys, JWT tokens

Professional Explanation

In enterprise React applications, API integration involves: - Centralized API Client: Single source for API calls - Error Handling: Consistent error handling patterns - Loading States: UI feedback during requests - Caching: Reducing unnecessary requests - Retry Logic: Handling transient failures - Authentication: Secure token management - Interceptors: Request/Response middleware - Validation: Data validation before/after requests

9.2 Fetch API

Simple Explanation

Fetch is a native JavaScript API for making HTTP requests. It's built into modern browsers and uses Promises. While more low-level than Axios, it's lightweight and doesn't require external dependencies.

Think of Fetch like sending a letter through the postal service - you address it (URL), include content (body), and wait for a response.

Technical Explanation

The Fetch API provides a JavaScript interface for accessing and manipulating parts of the HTTP pipeline. It's based on Promises and provides a more powerful and flexible feature set.

Key characteristics: - Promise-based: Uses async/await or .then - Response Object: Contains status, headers, body - Request Object: Configure request details - Headers Object: Manage request/response headers - AbortController: Cancel requests - Credentials: Handle cookies

Professional Explanation

While Fetch is built-in, it has limitations: - No Timeouts: No built-in timeout mechanism - No Request Cancellation: Need AbortController - No Interceptors: Need to implement manually - Error Handling: Only rejects on network errors, not HTTP errors - Complex Cookies: Some cookie handling needs configuration

Fetch Examples

// Basic GET request
function fetchUsers() {
    return fetch('https://api.example.com/users')
        .then(response => {
            if (!response.ok) {
                throw new Error(`HTTP error! status: ${response.status}`);
            }
            return response.json();
        })
        .then(data => {
            console.log('Users:', data);
            return data;
        })
        .catch(error => {
            console.error('Error fetching users:', error);
            throw error;
        });
}

// Fetch with AbortController (request cancellation)
function useFetchWithCancel(url) {
    useEffect(() => {
        const abortController = new AbortController();
        const signal = abortController.signal;

        const fetchData = async () => {
            try {
                const response = await fetch(url, { signal });
                const data = await response.json();
                // Handle data
            } catch (error) {
                if (error.name !== 'AbortError') {
                    console.error('Fetch error:', error);
                }
            }
        };

        fetchData();

        return () => {
            abortController.abort();
        };
    }, [url]);
}

// Fetch with timeout
function fetchWithTimeout(url, options = {}, timeout = 5000) {
    const abortController = new AbortController();
    const timeoutId = setTimeout(() => {
        abortController.abort();
    }, timeout);

    return fetch(url, {
        ...options,
        signal: abortController.signal
    })
        .then(response => {
            clearTimeout(timeoutId);
            return response;
        })
        .catch(error => {
            clearTimeout(timeoutId);
            if (error.name === 'AbortError') {
                throw new Error('Request timed out');
            }
            throw error;
        });
}

9.3 Axios

Simple Explanation

Axios is a popular HTTP client library that works in both browsers and Node.js. It provides a more convenient and feature-rich API than Fetch. It automatically transforms JSON data, handles errors better, and supports request/response interceptors.

Think of Axios like a premium courier service - it's more reliable, handles packaging and delivery automatically, and provides better tracking and error handling.

Technical Explanation

Axios is a promise-based HTTP client with extensive features:

Key characteristics: - Automatic JSON Transformation: Converts data to/from JSON - Interceptors: Request/Response interception - Cancellation: Request cancellation support - Timeouts: Built-in timeout handling - Progress Events: Upload/download progress - Multiple Environments: Browser and Node.js support - Error Handling: Better error handling than Fetch - Concurrent Requests: Multiple requests with Promise.all

Professional Explanation

Axios is preferred in enterprise applications for: - Interceptors: Centralized logging, auth, error handling - Consistent API: Same API for browser and Node.js - Better Error Handling: More informative error objects - Backwards Compatibility: Works with older browsers - Configuration: Global defaults and instance creation - Testing: Easier to mock and test

apiClient.interceptors.request.use(
    (config) => {
        // Add auth token
        const token = localStorage.getItem('authToken');
        if (token) {
            config.headers.Authorization = `Bearer ${token}`;
        }

        // Log request
        console.log('Request:', config.method, config.url);

        return config;
    },
    (error) => {

// Response interceptor
apiClient.interceptors.response.use(
    (response) => {
        // Log response
        console.log('Response:', response.status, response.config.url);
        return response;
    },
    (error) => {
        // Handle errors globally
        if (error.response) {
            // The request was made and the server responded with a status code
            console.error('Response error:', error.response.status, error.response.data);

            if (error.response.status === 401) {
                // Unauthorized - redirect to login
                localStorage.removeItem('authToken');
                window.location.href = '/login';
            }
        } else if (error.request) {
            // The request was made but no response was received
            console.error('No response received:', error.request);
        } else {
            // Something happened in setting up the request
            console.error('Request error:', error.message);
        }

        return Promise.reject(error);
    }
);

// Axios with cancellation
function useCancelableRequest() {
    const controllerRef = useRef(null);

    const makeRequest = useCallback(async (url) => {
        // Cancel previous request
        if (controllerRef.current) {
            controllerRef.current.abort();
        }

        controllerRef.current = new AbortController();

        try {
            const response = await apiClient.get(url, {
                signal: controllerRef.current.signal
            });
            return response.data;
        } catch (error) {
            if (axios.isCancel(error)) {
                console.log('Request canceled:', error.message);
                return null;
            }
            throw error;
        }
    }, []);

    const cancelRequest = useCallback(() => {
        if (controllerRef.current) {
            controllerRef.current.abort();
            controllerRef.current = null;
        }
    }, []);

    useEffect(() => {
        return () => {
            cancelRequest();
        };
    }, [cancelRequest]);

    return { makeRequest, cancelRequest };
}

9.4 REST API Integration

Simple Explanation

REST (Representational State Transfer) is an architectural style for designing APIs. It uses HTTP methods (GET, POST, PUT, DELETE) to perform operations on resources. REST APIs are the most common type of API you'll integrate with in React applications.

Think of REST like a library system - you can check out (GET) books, add new books (POST), update information (PUT), or remove books (DELETE).

Technical Explanation

REST APIs are built around resources and HTTP verbs: - GET: Retrieve a resource - POST: Create a new resource - PUT: Update a resource - PATCH: Partial update of a resource - DELETE: Remove a resource

Key concepts: - Resources: Represented by URLs (e.g., /users, /posts/123) - Methods: HTTP verbs for actions - Status Codes: 2xx success, 4xx client error, 5xx server error - Headers: Metadata like authentication, content type - Body: Data sent with POST, PUT, PATCH requests - Query Parameters: Filtering, sorting, pagination

Professional Explanation

REST API best practices: - Versioning: /api/v1/users - Consistent Naming: Plural nouns for resources - Status Codes: Appropriate HTTP status codes - Error Handling: Consistent error responses - Pagination: ?page=1&limit=10 - Filtering: ?status=active - Sorting: ?sort=name&order=asc - Field Selection: ?fields=id,name,email

9.5 Authentication and Authorization

Simple Explanation

Authentication is verifying who a user is (login), while authorization is determining what they can do (permissions). In React applications, this typically involves sending credentials to an API, receiving a token, and including that token in subsequent requests.

Think of authentication like showing your ID at a secure building - you prove who you are, and then you're given access based on your clearance level.

Technical Explanation

Authentication in React applications typically uses: - JWT (JSON Web Tokens): Stateless authentication tokens - Bearer Tokens: Sent in Authorization header - Refresh Tokens: Long-lived tokens for refreshing session - Session Cookies: Traditional session management - OAuth2/OpenID Connect: Third-party authentication

Key concepts: - Login: User provides credentials - Token: Server returns authentication token - Storage: Token stored in localStorage or memory - Interceptors: Automatically add token to requests - Refresh: Obtain new token when expired

Professional Explanation

Authentication best practices: - Secure Storage: Use httpOnly cookies for production - Token Expiration: Short-lived access tokens - Refresh Tokens: Secure refresh mechanism - CSRF Protection: Prevent cross-site request forgery - Logout: Clear tokens and redirect - Session Management: Handle concurrent sessions - Role-Based Access: Different permissions per role - Route Protection: Guard protected routes

Authentication Examples

// Auth service
class AuthService {
    constructor() {
        this.token = localStorage.getItem('authToken');
        this.refreshToken = localStorage.getItem('refreshToken');
        this.user = null;
        this.onTokenRefresh = null;
    }

    async login(email, password) {
        try {
            const response = await fetch('/api/auth/login', {
                method: 'POST',
                headers: { 'Content-Type': 'application/json' },
                body: JSON.stringify({ email, password })
            });

            if (!response.ok) {
                throw new Error('Login failed');
            }

            const data = await response.json();

            // Store tokens
            this.token = data.accessToken;
            this.refreshToken = data.refreshToken;
            this.user = data.user;

            localStorage.setItem('authToken', data.accessToken);
            localStorage.setItem('refreshToken', data.refreshToken);
            localStorage.setItem('user', JSON.stringify(data.user));

            return data;
        } catch (error) {
            throw new Error('Invalid credentials');
        }
    }

    async logout() {
        try {
            await fetch('/api/auth/logout', {
                method: 'POST',
                headers: {
                    'Authorization': `Bearer ${this.token}`
                }
            });
        } finally {
            this.token = null;
            this.refreshToken = null;
            this.user = null;
            localStorage.removeItem('authToken');
            localStorage.removeItem('refreshToken');
            localStorage.removeItem('user');
        }
    }

    async refreshAuthToken() {
        try {
            const response = await fetch('/api/auth/refresh', {
                method: 'POST',
                headers: { 'Content-Type': 'application/json' },
                body: JSON.stringify({ refreshToken: this.refreshToken })
            });

            if (!response.ok) {
                throw new Error('Refresh failed');
            }

            const data = await response.json();

            this.token = data.accessToken;
            localStorage.setItem('authToken', data.accessToken);

            return data.accessToken;
        } catch (error) {
            await this.logout();
            throw error;
        }
    }

    isAuthenticated() {
        return !!this.token;
    }

    getToken() {
        return this.token;
    }
}

const AuthContext = React.createContext(null);

function AuthProvider({ children }) {
    const [user, setUser] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);
    const authService = useRef(new AuthService());

    useEffect(() => {
        // Check for existing session
        const storedUser = localStorage.getItem('user');
        if (storedUser) {
            setUser(JSON.parse(storedUser));
        }
        setLoading(false);
    }, []);

    const login = async (email, password) => {
        setLoading(true);
        setError(null);

        try {
            const data = await authService.current.login(email, password);
            setUser(data.user);
            return data;
        } catch (err) {
            setError(err.message);
            throw err;
        } finally {
            setLoading(false);
        }
    };

    const logout = async () => {
        await authService.current.logout();
        setUser(null);
    };

    const value = {
        user,
        loading,
        error,
        login,
        logout,
        isAuthenticated: !!user,
        getToken: () => authService.current.getToken()
    };

    return (
        <AuthContext.Provider value={value}>
            {children}
        </AuthContext.Provider>
    );
}

// Axios interceptor with token refresh
function setupAxiosInterceptors(axiosInstance, authService) {
    // Request interceptor
    axiosInstance.interceptors.request.use(
        (config) => {
            const token = authService.getToken();
            if (token) {
                config.headers.Authorization = `Bearer ${token}`;
            }
            return config;
        },
        (error) => Promise.reject(error)
    );

    // Response interceptor for token refresh
    axiosInstance.interceptors.response.use(
        (response) => response,
        async (error) => {
            const originalRequest = error.config;

            // If error is 401 and not already retrying
            if (error.response?.status === 401 && !originalRequest._retry) {
                originalRequest._retry = true;

                try {
                    const newToken = await authService.refreshAuthToken();
                    originalRequest.headers.Authorization = `Bearer ${newToken}`;
                    return axiosInstance(originalRequest);
                } catch (refreshError) {
                    // Refresh failed - logout
                    await authService.logout();
                    window.location.href = '/login';
                    return Promise.reject(refreshError);
                }
            }

            return Promise.reject(error);
        }
    );
}

// Protected route
function ProtectedRoute({ children }) {
    const { isAuthenticated, loading } = useContext(AuthContext);
    const navigate = useNavigate();

    useEffect(() => {
        if (!loading && !isAuthenticated) {
            navigate('/login', { replace: true });
        }
    }, [isAuthenticated, loading, navigate]);

    if (loading) return <div>Loading...</div>;
    if (!isAuthenticated) return null;

    return children;
}

// Role-based authorization
function RoleProtectedRoute({ children, allowedRoles }) {
    const { user, loading } = useContext(AuthContext);
    const navigate = useNavigate();

    useEffect(() => {
        if (!loading) {
            if (!user) {
                navigate('/login', { replace: true });
            } else if (!allowedRoles.includes(user.role)) {
                navigate('/unauthorized', { replace: true });
            }
        }
    }, [user, loading, navigate, allowedRoles]);

    if (loading) return <div>Loading...</div>;
    if (!user || !allowedRoles.includes(user.role)) return null;

    return children;
}

            case 401:
                return Promise.reject(new AuthenticationError(data.message));

            case 403:
                return Promise.reject(new AppError('Permission denied', 'FORBIDDEN', status));

            default:
                return Promise.reject(new AppError(
                    data.message || 'Server error',
                    'SERVER_ERROR',
                    status
                ));
        }
    }

// Error boundary component
class ErrorBoundary extends React.Component {
    constructor(props) {
        super(props);
        this.state = { hasError: false, error: null };
    }

    static getDerivedStateFromError(error) {
        return { hasError: true, error };
    }

    componentDidCatch(error, errorInfo) {
        errorService.logError(error, {
            component: this.props.name,
            errorInfo
        });

        if (this.props.onError) {
            this.props.onError(error);
        }
    }

    render() {
        if (this.state.hasError) {
            return this.props.fallback || (
                <div className="error-boundary">
                    <h3>Something went wrong</h3>
                    <p>{errorService.handleError(this.state.error)}</p>
                    <button onClick={() => this.setState({ hasError: false })}>
                        Try again
                    </button>
                </div>
            );
        }

        return this.props.children;
    }
}

// Retry logic
function useRetryRequest(maxRetries = 3) {
    const [retryCount, setRetryCount] = useState(0);
    const [isRetrying, setIsRetrying] = useState(false);

    const retry = useCallback(async (requestFn, options = {}) => {
        setIsRetrying(true);

        try {
            const result = await requestFn();
            setRetryCount(0);
            return result;
        } catch (error) {
            if (retryCount < maxRetries) {
                setRetryCount(prev => prev + 1);

                // Exponential backoff
                const delay = Math.pow(2, retryCount) * 1000;
                await new Promise(resolve => setTimeout(resolve, delay));

                // Retry
                return retry(requestFn, { ...options, retry: retryCount + 1 });
            }

            throw error;
        } finally {
            setIsRetrying(false);
        }
    }, [retryCount, maxRetries]);

    return { retry, isRetrying, retryCount };
}

function FileUpload() {
    const [file, setFile] = useState(null);

    const [error, setError] = useState(null);

            // Validate file

            if (selectedFile.size > maxSize) {
                setError('File is too large. Maximum size is 5MB.');

            setSuccess(false);

            setFile(null);

        } catch (err) {
            setError(err.message);
        } finally {
            setUploading(false);
        }

                type="file"
                accept="image/*"
                onChange={handleFileChange}
                disabled={uploading}
            />

                <div>

                </div>

                onClick={handleUpload}

function FileUploadWithAxios() {
    const [selectedFiles, setSelectedFiles] = useState([]);
    const [uploadProgress, setUploadProgress] = useState({});
    const [uploading, setUploading] = useState(false);
    const [error, setError] = useState(null);

    const handleFileSelect = (e) => {
        const files = Array.from(e.target.files);

            const validTypes = ['image/jpeg', 'image/png', 'image/gif', 'application/pdf'];
            const maxSize = 10 * 1024 * 1024; // 10MB

            if (!validTypes.includes(file.type)) {

                return false;
            }

            if (file.size > maxSize) {
                setError(`File too large: ${file.name}`);
                return false;

            return true;
        });

        setError(null);

            const response = await axios.post('/api/upload', formData, {
                headers: {
                    'Content-Type': 'multipart/form-data'
                },
                onUploadProgress: (progressEvent) => {
                    const percentCompleted = Math.round(
                        (progressEvent.loaded * 100) / progressEvent.total
                    );
                    setUploadProgress(prev => ({
                        ...prev,
                        [file.name]: percentCompleted
                    }));
                }
            });

            return response.data;
        } catch (error) {
            throw new Error(`Upload failed for ${file.name}`);
        }
    };

    const handleUploadAll = async () => {
        setUploading(true);
        setError(null);
        const results = [];

        try {
            for (const file of selectedFiles) {
                const result = await uploadFile(file);
                results.push(result);
            }

            console.log('All uploads successful:', results);
            setSelectedFiles([]);
            setUploadProgress({});
        } catch (error) {
            setError(error.message);
        } finally {
            setUploading(false);
        }
    };

    const handleRemoveFile = (fileName) => {
        setSelectedFiles(prev => prev.filter(f => f.name !== fileName));
        const newProgress = { ...uploadProgress };
        delete newProgress[fileName];
        setUploadProgress(newProgress);
    };

    return (
        <div>
            <input
                type="file"
                multiple
                onChange={handleFileSelect}
                disabled={uploading}
                accept=".jpg,.jpeg,.png,.gif,.pdf"
            />

            {selectedFiles.length > 0 && (

                </div>

        </div>
    );

                    'Authorization': `Bearer ${getToken()}`
                }
            });

            if (!response.ok) {
                throw new Error('Download failed');
            }

            const blob = await response.blob();
            const url = window.URL.createObjectURL(blob);
            setDownloadUrl(url);

            // Create download link and trigger download
            const link = document.createElement('a');
            link.href = url;
            link.download = `file-${fileId}.pdf`;
            document.body.appendChild(link);
            link.click();
            document.body.removeChild(link);

            // Clean up URL
            setTimeout(() => {
                window.URL.revokeObjectURL(url);
                setDownloadUrl(null);
            }, 5000);
        } catch (error) {
            setError('Failed to download file. Please try again.');
        } finally {
            setLoading(false);
        }
    };

    return (
        <div>
            <button
                onClick={() => downloadFile(123)}
                disabled={loading}
            >
                {loading ? 'Downloading...' : 'Download File'}
            </button>
            {error && <div className="error">{error}</div>}
            {downloadUrl && <div>Download complete!</div>}
        </div>
    );
}

// Pagination component
function Pagination({ 
    currentPage, 
    totalItems, 
    pageSize, 
    onPageChange 
}) {
    const totalPages = Math.ceil(totalItems / pageSize);
    const maxVisible = 5;

    const getPageNumbers = () => {
        const pages = [];
        let startPage = Math.max(1, currentPage - Math.floor(maxVisible / 2));
        let endPage = Math.min(totalPages, startPage + maxVisible - 1);

        if (endPage - startPage < maxVisible - 1) {
            startPage = Math.max(1, endPage - maxVisible + 1);
        }

        for (let i = startPage; i <= endPage; i++) {
            pages.push(i);
        }

        return pages;
    };

    if (totalPages <= 1) return null;

    return (
        <div className="pagination">
            <button
                onClick={() => onPageChange(currentPage - 1)}
                disabled={currentPage === 1}
            >
                Previous
            </button>

            {currentPage > Math.floor(maxVisible / 2) + 1 && (
                <>
                    <button onClick={() => onPageChange(1)}>1</button>
                    <span>...</span>
                </>
            )}

            {getPageNumbers().map(page => (
                <button
                    key={page}
                    className={page === currentPage ? 'active' : ''}
                    onClick={() => onPageChange(page)}
                >
                    {page}
                </button>
            ))}

            {currentPage < totalPages - Math.floor(maxVisible / 2) && (
                <>
                    <span>...</span>
                    <button onClick={() => onPageChange(totalPages)}>
                        {totalPages}
                    </button>
                </>
            )}

            <button
                onClick={() => onPageChange(currentPage + 1)}
                disabled={currentPage === totalPages}
            >
                Next
            </button>

            <span className="pagination-info">
                Page {currentPage} of {totalPages} ({totalItems} items)
            </span>
        </div>
    );
}

function usePaginatedData(initialParams = {}) {

        total: 0,
        totalPages: 0

        setError(null);

        try {
            const queryString = new URLSearchParams(
                Object.entries(mergedParams).reduce((acc, [key, value]) => {
                    if (value !== undefined && value !== null && value !== '') {
                        acc[key] = value;
                    }
                    return acc;
                }, {})
            ).toString();

            const response = await fetch(`/api/data?${queryString}`);
            if (!response.ok) {
                throw new Error('Failed to fetch data');
            }

            const result = await response.json();

            setPagination({
                page: result.page || mergedParams.page,
                limit: result.limit || mergedParams.limit,
                total: result.total || 0,
                totalPages: result.totalPages || Math.ceil((result.total || 0) / (result.limit || mergedParams.limit))
            });

            if (newParams.page !== undefined || newParams.limit !== undefined) {
                setParams(prev => ({ ...prev, ...newParams }));
            }
        } catch (error) {
            setError(error.message);
        } finally {
            setLoading(false);
        }
    }, [params]);

    const updateParams = (newParams) => {
        setParams(prev => ({ ...prev, ...newParams }));
        fetchData({ ...params, ...newParams });
    };

    const changePage = (page) => {
        updateParams({ page });
    };

    const changeLimit = (limit) => {
        updateParams({ page: 1, limit });
    };

    const changeSort = (sort, order = 'asc') => {
        updateParams({ sort, order, page: 1 });
    };

    const changeFilter = (filters) => {
        updateParams({ ...filters, page: 1 });
    };

        fetchData();
    }, []);

    return {
        data,
        loading,
        error,
        pagination,
        params,
        fetchData,
        updateParams,
        changePage,
        changeLimit,
        changeSort,
        changeFilter
    };
}

// Component using paginated data
function DataTable() {
    const {
        data,
        loading,
        error,
        pagination,
        params,
        changePage,
        changeLimit,
        changeSort,
        changeFilter
    } = usePaginatedData();

    const [searchTerm, setSearchTerm] = useState('');
    const [debouncedSearch, setDebouncedSearch] = useState('');
    const [statusFilter, setStatusFilter] = useState('');

    // Debounce search
    useEffect(() => {
        const timer = setTimeout(() => {
            setDebouncedSearch(searchTerm);
        }, 300);

        return () => clearTimeout(timer);
    }, [searchTerm]);

    // Update filters when debounced search changes
    useEffect(() => {
        if (debouncedSearch !== undefined) {
            changeFilter({ search: debouncedSearch, status: statusFilter });
        }
    }, [debouncedSearch, statusFilter]);

    if (loading) return <div>Loading...</div>;
    if (error) return <div>Error: {error}</div>;

    return (
        <div>
            <div className="filters">
                <input
                    placeholder="Search..."
                    value={searchTerm}
                    onChange={(e) => setSearchTerm(e.target.value)}
                />
                <select
                    value={statusFilter}
                    onChange={(e) => setStatusFilter(e.target.value)}
                >
                    <option value="">All Status</option>
                    <option value="active">Active</option>
                    <option value="inactive">Inactive</option>
                </select>
                <select
                    value={`${params.sort}-${params.order}`}
                    onChange={(e) => {
                        const [sort, order] = e.target.value.split('-');
                        changeSort(sort, order);
                    }}
                >
                    <option value="createdAt-desc">Newest</option>
                    <option value="createdAt-asc">Oldest</option>
                    <option value="name-asc">Name A-Z</option>
                    <option value="name-desc">Name Z-A</option>
                </select>
            </div>

            <table>
                <thead>
                    <tr>
                        <th>ID</th>
                        <th>Name</th>
                        <th>Status</th>
                        <th>Created At</th>
                    </tr>
                </thead>
                <tbody>
                    {data.map(item => (
                        <tr key={item.id}>
                            <td>{item.id}</td>
                            <td>{item.name}</td>
                            <td>{item.status}</td>
                            <td>{new Date(item.createdAt).toLocaleDateString()}</td>
                        </tr>
                    ))}
                </tbody>
            </table>

            <Pagination
                currentPage={pagination.page}
                totalItems={pagination.total}
                pageSize={pagination.limit}
                onPageChange={changePage}
            />

            <div className="page-size">
                <label>Items per page:</label>
                <select
                    value={pagination.limit}
                    onChange={(e) => changeLimit(Number(e.target.value))}
                >
                    <option value="5">5</option>
                    <option value="10">10</option>
                    <option value="25">25</option>
                    <option value="50">50</option>
                    <option value="100">100</option>
                </select>
            </div>
        </div>
    );
}

// Infinite scroll pagination
function InfiniteScroll() {
    const [items, setItems] = useState([]);
    const [page, setPage] = useState(1);
    const [loading, setLoading] = useState(false);
    const [hasMore, setHasMore] = useState(true);
    const observerRef = useRef(null);

    const loadMore = useCallback(async () => {
        if (loading || !hasMore) return;

        setLoading(true);
        try {
            const response = await fetch(`/api/items?page=${page}&limit=20`);
            const data = await response.json();

            setItems(prev => [...prev, ...data.items]);
            setHasMore(data.hasMore);
            setPage(prev => prev + 1);
        } catch (error) {
            console.error('Error loading items:', error);
        } finally {
            setLoading(false);
        }
    }, [page, loading, hasMore]);

    useEffect(() => {
        const observer = new IntersectionObserver(
            (entries) => {
                if (entries[0].isIntersecting) {
                    loadMore();
                }
            },
            { threshold: 0.1 }
        );

        if (observerRef.current) {
            observer.observe(observerRef.current);
        }

        return () => {
            if (observerRef.current) {
                observer.disconnect();
            }
        };
    }, [loadMore]);

    return (
        <div>
            {items.map(item => (
                <div key={item.id}>
                    <h3>{item.name}</h3>
                    <p>{item.description}</p>
                </div>
            ))}

            {loading && <div>Loading more items...</div>}

            <div ref={observerRef}>
                {hasMore && !loading && <div>Load more</div>}
                {!hasMore && <div>End of list</div>}
            </div>
        </div>
    );
}

9.9 Common Mistakes and Best Practices

9.9.1 Common Mistakes

// ❌ Not handling loading states
function BadComponent() {
    const [data, setData] = useState(null);

    useEffect(() => {
        fetchData().then(setData);
    }, []);

    // ❌ data might be null when rendering
    return <div>{data.name}</div>;
}

// ✅ Handle loading and error states
function GoodComponent() {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        fetchData()
            .then(setData)
            .catch(setError)
            .finally(() => setLoading(false));
    }, []);

    if (loading) return <div>Loading...</div>;
    if (error) return <div>Error: {error}</div>;
    if (!data) return <div>No data</div>;

    return <div>{data.name}</div>;
}

// ❌ Not cleaning up requests
function BadEffect({ userId }) {
    const [user, setUser] = useState(null);

    useEffect(() => {
        fetchUser(userId).then(setUser);
        // ❌ No cleanup - memory leak
    }, [userId]);
}

// ✅ Clean up requests
function GoodEffect({ userId }) {
    const [user, setUser] = useState(null);

    useEffect(() => {
        const abortController = new AbortController();

        fetchUser(userId, { signal: abortController.signal })
            .then(setUser)
            .catch(error => {
                if (error.name !== 'AbortError') {
                    console.error('Error:', error);
                }
            });

        return () => abortController.abort();
    }, [userId]);
}

// ❌ Storing sensitive data in localStorage
function BadAuth() {
    const login = async (email, password) => {
        const response = await fetch('/api/login', {
            method: 'POST',
            body: JSON.stringify({ email, password })
        });
        const data = await response.json();
        localStorage.setItem('token', data.token); // ❌ Not secure
    };
}

// ✅ Use httpOnly cookies or secure storage
function GoodAuth() {
    const login = async (email, password) => {
        const response = await fetch('/api/login', {
            method: 'POST',
            body: JSON.stringify({ email, password }),
            credentials: 'include' // ✅ Send cookies
        });
        // Token stored in httpOnly cookie
    };
}

9.10 Interview Questions

Junior Level Questions

Q: What is the difference between Fetch and Axios?

Answer: - Fetch: Native browser API, requires JSON parsing, no timeouts - Axios: Third-party library, automatic JSON parsing, interceptors, timeouts

// Fetch
fetch('/api/users')
    .then(res => res.json())
    .then(data => console.log(data));

// Axios
axios.get('/api/users')
    .then(res => console.log(res.data));

Q: How do you handle API errors in React?

Answer: Use try/catch with async/await, check response status, show user-friendly error messages, and log errors for debugging.

Mid Level Questions

Q: How do you implement token-based authentication?

Answer: 1. User logs in with credentials 2. Server returns JWT token 3. Store token securely 4. Include token in Authorization header 5. Handle token expiration with refresh tokens

axios.interceptors.request.use(config => {
    const token = localStorage.getItem('token');
    if (token) {
        config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
});

Q: What is the purpose of React Query?

Answer: React Query handles server state by providing: - Automatic caching - Background updates - Stale-while-revalidate - Pagination and infinite queries - Mutations with optimistic updates

Senior Level Questions

Q: How do you handle API caching in React applications?

Answer: Use React Query or SWR for server state caching with features like: - Cache invalidation - Stale-while-revalidate - Cache persistence - Selective caching

const { data } = useQuery({
    queryKey: ['user', userId],
    queryFn: () => fetchUser(userId),
    staleTime: 5 * 60 * 1000, // 5 minutes
    cacheTime: 10 * 60 * 1000, // 10 minutes
});

Q: How do you implement optimistic updates?

Answer: Update UI optimistically before server confirms, then rollback on error.

const mutation = useMutation({
    mutationFn: updateTodo,
    onMutate: async (newTodo) => {
        await queryClient.cancelQueries(['todos']);
        const previous = queryClient.getQueryData(['todos']);
        queryClient.setQueryData(['todos'], old => [...old, newTodo]);
        return { previous };
    },
    onError: (err, newTodo, context) => {
        queryClient.setQueryData(['todos'], context.previous);
    }
});
