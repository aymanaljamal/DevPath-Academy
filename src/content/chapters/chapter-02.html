JavaScript Required for React

2.1 Introduction to JavaScript for React

Simple Explanation

JavaScript is the foundation of React. Before learning React, you need to understand JavaScript well, just like you need to know how to read and write before writing a book. This chapter covers all the JavaScript concepts you'll need to build professional React applications.

Think of JavaScript as the engine that powers your React application. Every React component, every interaction, every data fetch - it all relies on JavaScript.

Technical Explanation

React is built on modern JavaScript (ES6+). Understanding JavaScript thoroughly is essential because:

  1. React Components are JavaScript functions or classes
  2. JSX is transformed into JavaScript function calls
  3. State Management relies on JavaScript objects and functions
  4. Event Handling uses JavaScript event system
  5. Data Flow is managed through JavaScript data structures

Professional Explanation

In enterprise React development, JavaScript proficiency is non-negotiable. You'll need to understand:

  • Functional Programming Concepts: Immutability, pure functions, composition
  • Asynchronous Programming: Promises, async/await, event loop
  • Memory Management: Garbage collection, memory leaks prevention
  • Type Systems: TypeScript interfaces, generics, utility types
  • Module Systems: ES modules, dynamic imports, code splitting

2.3.4 Functions vs Arrow Functions - this Binding

// Traditional function - has its own 'this'
function User(name) {
    this.name = name;
    this.greet = function() {
        console.log(`Hello, ${this.name}`); // 'this' refers to User instance
    };
}

// Arrow function - uses parent's 'this'
function UserArrow(name) {
    this.name = name;
    this.greet = () => {
        console.log(`Hello, ${this.name}`); // 'this' from parent scope
    };
}

// React example - Arrow functions preserve 'this'
class Counter extends React.Component {
    constructor(props) {
        super(props);
        this.state = { count: 0 };
    }

    // Arrow function - no need to bind
    handleClick = () => {
        this.setState({ count: this.state.count + 1 });
    };

    // Regular function - needs binding
    handleClick2() {
        this.setState({ count: this.state.count + 1 });
    }

    render() {
        return (
            <button onClick={this.handleClick}>
                Count: {this.state.count}
            </button>
        );
    }
}

// Retry logic with async/await
async function fetchWithRetry(url, maxRetries = 3) {
    let lastError;

    for (let attempt = 1; attempt <= maxRetries; attempt++) {
        try {
            const response = await fetch(url);
            if (!response.ok) {
                throw new Error(`HTTP error! status: ${response.status}`);
            }
            return await response.json();
        } catch (error) {
            lastError = error;
            console.log(`Attempt ${attempt} failed: ${error.message}`);

            if (attempt < maxRetries) {
                // Exponential backoff
                const delay = Math.pow(2, attempt) * 1000;
                await new Promise(resolve => setTimeout(resolve, delay));
            }
        }
    }

    throw new Error(`Failed after ${maxRetries} attempts: ${lastError.message}`);
}

// Custom hook using all JavaScript features
function useFetchData(url, options = {}) {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(false);
    const [error, setError] = useState(null);

            try {
                setLoading(true);
                setError(null);

                const response = await fetch(url, {
                    ...options,
                    signal: abortController.signal
                });

                if (!response.ok) {
                    throw new Error(`HTTP error! status: ${response.status}`);
                }

                setData(result);

                setLoading(false);
            }
        };

        fetchData();

        return () => {
            abortController.abort();
        };
    }, [url, JSON.stringify(options)]);

    return { data, loading, error };
}

Q: What's the difference between let, const, and var?

Answer: - var: Function-scoped, can be redeclared, hoisted with undefined - let: Block-scoped, cannot be redeclared, hoisted but not initialized - const: Block-scoped, cannot be reassigned, hoisted but not initialized

Q: What is the difference between == and ===?

Answer: - ==: Loose equality, performs type coercion - ===: Strict equality, checks both value and type

console.log(5 == '5'); // true (string converted to number)
console.log(5 === '5'); // false (different types)
console.log(null == undefined); // true
console.log(null === undefined); // false
